# 援光 HelpLight — 灾害求助信息结构化与分诊台

HER Hack-Astron #7 参赛作品（赛道一 · 应急救灾 / 求助信息结构化）。

把散落在社交平台、微信群、电话记录里的口语化灾害求助文本，用 **Spark-X2.6-4B 在本地**
逐条抽取为结构化字段（地点、人数、人员构成、需求、紧急程度、联系方式、中英双语摘要），
生成按紧急程度排序的分诊清单，供一线社区志愿者与民间救援协调员人工复核后使用。
全程本地推理，不调用任何云端 API。

> **边界声明**：本工具为原型工具，**不替代 110 / 119 / 120 与官方救援调度**；
> 模型抽取结果**必须经人工复核**后才能用于救援行动；
> 联系方式等个人信息**仅在本机处理**，不上传任何云端。

## 快速开始

环境要求：Python 3.10+（应用仅用标准库，无第三方依赖）；Ollama 0.40.9 + 官方
GGUF 量化权重（准备方法见投稿帖第三节与 `models/` 目录）。

```bash
# 1) 启动模型服务（端点 http://127.0.0.1:11434/v1，模型名 spark-x2.6-4b）
ollama serve

# 2) 启动应用（真实模型端点）
cd app
MODEL_ENDPOINT=http://127.0.0.1:11434/v1 MODEL_NAME=spark-x2.6-4b MODEL_TIMEOUT=900 python3 server.py
```

浏览器打开 http://127.0.0.1:8000 ，可一键载入 3 条内置脱敏虚构示例体验完整流程。
没有模型环境时，可用 `app/stub_server.py` 假端点先跑通界面（结果不代表模型真实效果）。

## 目录

- `app/` — Web 应用（服务、模型接入层、内置示例、stub、前端单页）
- `models/` — Ollama Modelfile 与权重下载脚本（权重本体请按脚本从官方仓库获取）
- `eval/` — 12 条评估集（gold.json）、运行脚本与两轮评估报告（v1 定版 / v2 回滚记录）
- `demo/` — 演示脚本、截图清单与真实运行输出归档
- `logs/` — 联调与冒烟测试记录（integration-test.md 等）

## 效果（v1 定版，真实模型运行）

12 条评估样本 × 8 字段：严格准确率 74.0%，可用率 96.9%，紧急程度研判 12/12，
零虚构编造。失败案例与局限如实记录在 `eval/EVAL-REPORT.md` 与投稿帖第六节。
